# The Daily Beet — Website

Concept homepage for **The Daily Beet**, a plant-forward café & cold-pressed juice bar in New Orleans (since 2017).

> From the soil to your bowl.

## Preview

Open `index.html` in a browser — it's a single, self-contained file (no build step, no dependencies). Works in light and dark mode.

## Design direction

- **Palette:** beet crimson `#B01E4F` as the signature accent, warm linen ground, leaf green + turmeric gold supports. Chosen to own a color the category (Sweetgreen, Life Alive, Pura Vida) leaves on the table — and it's literally the brand's namesake.
- **Type:** humanist serif display (Palatino/Book Antiqua) for warmth + NOLA soul, system sans for body, letter-spaced labels.
- **Sections:** hero, ingredient ticker, "Our Roots" story band, editorial market-list menu, produce-color gallery, three location cards, order CTA, footer.

## Notes for production

- Menu items/prices are representative placeholders — wire to the real POS/online-ordering provider.
- Gallery tiles are CSS art standing in for real food photography and/or an Instagram feed.
- Order buttons are stubbed; connect to the ordering platform of choice.
