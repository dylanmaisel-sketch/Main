# The Daily Beet — Website

Concept homepage for **The Daily Beet**, a plant-forward café & cold-pressed juice bar in New Orleans (since 2017).

> From the soil to your bowl.

## Two concepts

Each is a single, self-contained file — no build step, no dependencies — with light + dark modes.

### Concept A — Crimson Editorial (`index.html`)
Warm, artisanal, New Orleans soul.
- **Palette:** beet crimson `#B01E4F` signature accent, warm linen ground, leaf green + turmeric gold. Owns a color the category (Sweetgreen, Life Alive, Pura Vida) leaves on the table — and it's literally the brand's namesake.
- **Type:** humanist serif display (Palatino/Book Antiqua) + system sans body, letter-spaced labels.
- **Sections:** hero, ingredient ticker, "Our Roots" story band, editorial market-list menu, produce gallery, three locations, CTA.

### Concept B — Bright / Photo-First (`concept-b/index.html`)
Punchy, polychrome, DTC juice-bar energy (the Pura Vida lane).
- **Palette:** multi-accent — pitaya pink `#FF3E7F`, sunshine `#FFBE24`, lime `#74C93B`, grape `#7A3CC4` — on bright paper.
- **Type:** oversized lowercase heavy grotesque (modern sans) display.
- **Sections:** bento hero, marquee, horizontal scroll-snap menu rail, full-bleed "Our Roots," bento feed, color location cards, sticky bottom order bar.

## Notes for production

- Menu items/prices are representative placeholders — wire to the real POS/online-ordering provider.
- Gallery tiles are CSS art standing in for real food photography and/or an Instagram feed.
- Order buttons are stubbed; connect to the ordering platform of choice.
